## QR-Based Garbage Reporting System

### About the Project
The QR-Based Garbage Reporting System is a web-based project designed to improve cleanliness and waste management on college campuses.

Each dustbin has a unique QR code. Users can scan the QR code to open a webpage for that particular dustbin and report issues such as:
- Dustbin full
- Garbage overflowing
- Bad smell
- Dustbin damaged

Authorised cleaning staff can view reports, monitor their status, and take appropriate action.

### Objectives
- Improve campus cleanliness.
- Make garbage reporting easy and quick.
- Identify the exact dustbin with a problem.
- Help cleaning staff manage complaints efficiently.
- Encourage a clean and hygienic environment.

### How It Works
1. Each dustbin receives a unique QR code.
2. A user scans the QR code using a mobile phone.
3. The website opens for the selected dustbin.
4. The user selects the problem and submits a report.
5. The report is stored in a database.
6. Authorised staff view the report and update its status.

### Technologies Used
- HTML – Website structure
- CSS – Website design
- JavaScript – Website functionality
- GitHub Pages – Website hosting
- Firebase Authentication – Staff login
- Cloud Firestore – Report database

### Main Features
- Unique QR code for each dustbin
- Mobile-friendly reporting page
- Garbage problem reporting
- Staff login
- Complaint status tracking
- Admin management of dustbins and QR codes
